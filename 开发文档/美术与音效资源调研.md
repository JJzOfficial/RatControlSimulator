## 1. 决策结论

1. P0 可以先不花钱：用 CC0 Rat 完成一只鼠的完整业务闭环，用免费手臂作操作底模，用 Poly Haven 材质和少量道具搭建自制住宅模块，用 CC0 音效建立白天、夜间和工具反馈。
2. 蟑螂有廉价现成低模，但半写实近景效果与动作需要补制。蚊子和刺猬本轮没有核实到预算内、许可清晰、能直接发行的完整资产；P0 必须为它们预留项目制作或委托工作。刺猬不能靠换贴图完成缩球。
3. 不建议一次购买“大而全动物包”。45 条图鉴可共享行为、骨架和材质流程，但不能把一种模型缩放换色后全部标成不同物种。近景图鉴需要独立可辨识的轮廓。
4. 环境、普通静态道具和声音有充分的免费合法来源。总预算优先留给主角鼠、伙伴动作、第一人称操作以及刺猬缩球等实际缺口。
5. 500–1000 元能够支持代表性资产原型和少数低价采购，不能承诺买齐 45 种近景半写实动物及全部游戏动作。自制工时与委托报价必须另行估算。

### 3.1 P0 蚊与刺猬的明确缺口

- **蚊：**本轮没有核实到许可与动画都清楚、可直接发行的廉价完整包。建议自行制作“近景标本模型 + 远景飞虫实例 / 粒子”两套表现。飞行翅膀可用少量透明卡片或受控振翅，停落体保留长口器、细腿和腹部轮廓；不要用蜻蜓、蜂或普通飞蝇直接改名。
- **刺猬：**本轮没有核实到可信、半写实、免费可商用的完整资产。最新决定为 **P0 保留专用简模**，具有正常行走体和缩球体；可用专门 BlendShape 或两形态切换配合动画，并制作可读的刺毛贴图。不要以 Sonic 同人、头骨扫描或 2D 图像填充覆盖表。
- **蟑螂：**Critter Pack 可以承担远景或原型；近景 I01 / I02 至少需要不同体型、前胸背板 / 翅纹与大小，补停顿、触角、逃窜、翻倒 / 清理状态。其页面没有承诺两种生物学蟑螂。

仅保留为“待核验来源”的 [Mosquito / adarshktk](https://sketchfab.com/3d-models/mosquito-474d2ea54af64114b2b5b1d2f6b18f8a)：索引显示免费、CC Attribution、32.6K tris、2K 贴图，但原页未完整打开，CC 版本、骨骼与动画未确认。它是 C 级条目，**不计为可发行或采购通过的蚊资产**。即使许可补齐，也需重拓扑与振翅制作。

## 10. HDRP 与性能验收要求

- 运行场景先用普通 HDRP Lit 和贴图表现毛发，不默认使用 shell fur、大片透明毛片或所有动物实时高成本阴影。
- 网页面数不等于实际 Draw Call 或帧时。建议小型普通动物先以约 0.5–4K tris、1K 纹理评估，伙伴先以约 1–8K tris、1K–2K 纹理评估；这是起始制作目标，不能反推性能已经达标。
- 近景图鉴和场景远景可以使用不同 LOD。微小飞虫远景优先实例 / 粒子，只有检查或捕捉近景加载完整模型；不能让每只远处蚊子都使用 32K tris。
- 源材质的 Metallic / Roughness / AO 不直接等于 HDRP Mask Map。导入时核对通道、法线方向、透明、裁剪、双面和尺度，避免一键升级后以为完成。
- Poly Haven 原始 2M / 5M tris 植被必须选低 LOD、重拓扑或烘焙；高分辨率下载只作制作源，不默认全进构建。
- 每个关键包先在项目真实版本导入独立测试场景，核对骨数、权重、动作循环、Root Motion、脚滑、材质和 LOD，再放入 L01 / L03 的实际密度场景。
- 在 GTX 1660 6 GB、1080p 记录 CPU / GPU 帧时、显存、批次、峰值动物数与夜间灯光；本轮没有测量结果，不把目标 60 FPS 写成已达成。
