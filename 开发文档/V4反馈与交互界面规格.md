# V4反馈与交互界面规格

版本：FullGame-spec-1.0。适用：下一步完整白模版，六项均待工程实现和验证。用户基线：RiverbendDemoV4；不单独制作修复Demo。

F01是本轮明确的无声规则，不是等待补脚步音效。蹲行仅取消脚步声音与对应AI刺激；跳落、使用工具、武器、物品碰撞和犬吠仍按来源发声。站立/跑动切为蹲行时停止后续脚步触发，清掉残余脚步声刺激/HUD包络；刚落地的冲击提示按本身衰减，不清空其他声源。原地按移动键被墙挡住不能凭输入产生脚步。

## 2. 诱饵：先明确反应，再保留捕获不确定性

基础有效范围从V4的4.5m改为9m工程初值，诱饵经验一/二级为12.15/15.3m。半径用世界距离粗筛，合法气味路线长度上限为该有效半径×1.5。跨开放门/连通鼠道可以闻到，密封墙、楼板和封堵边不传；不再要求动物先直接看到笼子才感知。闭门无路时不从另一房间强拉，楼上需有连通楼梯/鼠道。

每秒评估一次同区域诱饵，安全条件满足后3秒内必出现可读的闻味/抬头状态。可读反应是确定的，进笼不是定时保底。基础吸引评分为 `0.45+0.25×饥饿+0.20×偏好+0.10×胆量−0.50×警戒比例`；合法诱饵至少0.65基础兴趣，安全目标达到0.55可接近。食物和诱饵共用决策层，诱饵只在安全且有路时优先于普通巡游；直接威胁/受控状态优先于食物。

进入ObserveBait停2–6秒，随后ApproachBait沿路径接近；在入口复核门状态、尺寸与占用，再进行InspectEntrance。首次试探可退开一次，安全后5–12秒再评估；退开不把所有鼠重置到一分钟无反应。持续盯守、走近和照光仍增加警戒；威胁解除后必须能恢复。饥饿/胆量只调节观察与退开，不重复乘多重低概率导致永久忽略。

笼关门要求目标连续经过EntrancePlane进入InnerVolume；机械夹要求身体实际进入压板区。9m仅是感知半径，绝不是捕获半径。关门时1只目标取得容器占用，其他个体重新选目标；诱饵不可用时立即撤销兴趣。无饵只允许原巡游真实经过入口后触发，不发诱饵刺激。捕获提交才消费一份装置饵量；取消、无路、满笼不扣。

开发诊断可显示“超距/气味无路/受惊/目标不适配/被占用”，玩家仅看闻味、观察和接近反馈，不展示AI评分公式。实测固定种子20次：2/5/8m有饵 vs 无饵；9m外不得由基础饵新吸引；全封、跨层、玩家靠近、照光及两鼠争笼分别记录。安全8m组以3秒内反应和120秒内显著多于无饵组的接近/捕获为门槛，不把百分百入笼作为合格要求。

## 3. 持续交互的唯一时间源

按键超过0.35秒确认长按，再建立 `InteractionSession {token, actionId, targetId, toolInstanceId, durationSeconds, elapsedSeconds, state, revision}`。本版统一不把识别长按的0.35秒算入作业；圆环从Session启动的0开始。短按在阈值前松键才提交拾取，跨阈值永久抑制该次短按。E作业与长Q调查同一时刻只能有一个会话，互不借用elapsed字段。

duration在动作开始时由基础时长和技能求最终值并冻结，最低0.25秒。清源/排水/修缮3秒，虫尸清理与开笼/复位1.2秒，调查2秒，转移2.5秒，装袋/部署2秒。修缮/清洁减时、转移减时等对同动作取最大减幅，不累乘。UI只读Session的 `normalizedProgress=elapsed/duration`，不得再次DescribeAction或按当前工具推测分母。

每个有效逻辑步先验证目标、视线、距离、工具实例和余量，更新elapsed；到达duration后重验证并原子提交。仅Accepted后显示完整圆环和完成反馈；Rejected显示原因并结束会话，不让100%悬着等另一个隐藏计时器。渲染插值不得提前超过领域进度，提交成功的显示误差最多一渲染帧。动画事件只表现，无权完成任务、扣资源或发奖励。

松键/换目标/换工具/超距/遮挡/受击取消并清零，未提交不扣资源。Esc或详细面板先取消会话再暂停，避免关闭后自动继续；不取消的系统暂停只冻结有效时钟。保存前取消未提交会话；读档不自动延续长按。配置变化不在会话中途改duration。0.6/1.2/2/3秒、全部技能、30/60/144FPS、暂停/取消/最后帧失败均要测。

## 4. 随机作业点：用户已答复的最终规则

2026-11-14用户选择：“新游戏、每次接新委托重抽；载入存档保持原位置”。主菜单新建档案进入公司，第一次确认出发时生成第一份布局；公司本身不随机拆建。每次确认新委托/重玩才新建runId和layoutSeed。启动程序、选择已有档、恢复现场、入夜、切菜单均不重抽。

每个逻辑作业ID与实际anchor分开，F01不是永远同一墙点。按任务类型与分区抽候选；至少4个合法候选/必需点，关键洞口至少分布两段可辨墙面。选择需同时绑定破损模型、Target、Collider、贴花占位、交互站位、对应导航边和修复后模型；禁止只移动发光图标、把裂口留在原地。鼠洞必须位于有真实出口/鼠道的墙脚，漏水只落管道/水槽，破网只落围栏，受害树只能落可达树段。

事务式生成：固定预算与逻辑点→独立Layout随机流→筛选候选→玩家站位/交互射线/货物通行/重叠/导航校验→生成布局签名→合法时整批提交。与上一局签名相同且存在其他合法组合，换确定性候选重试；最多32次，不拿不可达组合凑随机。用版本化稳定hash，不用跨进程不稳定的string.GetHashCode。没有合法组合时阻止出发并保留公司物资，给出具体节点错误；不退化成固定原点。

保存 `layoutVersion, seed, selectedAnchors, poses, boundEdgeIds, previousSignature, currentSignature`。已完成状态按逻辑作业ID恢复，模型和边按同一快照创建；读档先恢复真实位置，再恢复作业/封边。旧档位置沿用旧结果，不强制打乱已维修点。新游戏独立seed但可合法偶然撞种子；同一档连续新单必须避免完整重复组合。

## 5. 主菜单与新档/载入流程

纯色背景、游戏标题与四个文字按钮，无图片、无开场动画依赖。按钮固定为“开始游戏 / 载入存档 / 设置 / 退出游戏”，英文为Start Game / Load Game / Settings / Quit Game；上下/W/S切焦点、Enter确认、鼠标点击、Esc返回。程序启动仅加载设置和档案摘要，不创建活动场景、不给礼包、不推进旧委托。

开始游戏进入3档位选择：空位可新建；占用位显示地图/阶段/保存时间并明确覆盖确认。未确认不得删旧档。新档公司出生、初始300与一次礼包。取消返回主菜单。载入页面列每档手动/最近自动及备份恢复入口，明确时间、版本、公司/现场/昼夜；无档显示说明并仍可返回，无隐形自动继续。恢复期间锁输入，成功才显示世界，失败留菜单说明。

设置从主菜单/暂停共用：语言、分辨率/窗口/画质、鼠标灵敏度/FOV、音量分轨、全部实际动作重绑、蹲/瞄/屏息按住或切换、字幕/声音方向/低晃动/Q柔和/UI缩放。显示模式变更15秒内确认，否则回退；设置不依赖创建profile。退出游戏在主菜单直接退出；游戏内暂停有“保存并回主菜单 / 回主菜单 / 返回游戏 / 退出”，存在未保存变化时说明保存选择。保存失败不宣称已存。

## 6. HUD布局与声音表现

基准1920×1080，安全边距32px。左下容器LeftBottomStatus锚点(0,0)、pivot(0,0)，距离左/下32px，宽320、高约220；自下向上依次声音提示、体力、按需屏息、生命/Q/伙伴短状态。屏息只精确瞄准显示，隐藏后自动收拢。声音输出强度条与可选动物/工具方向提示都在此容器，方向用小箭头/类别文字，不在屏幕边缘另散放一套。

物品快捷栏仍在底部中央，可扩到10格；当前格耐久随格显示。主目标/保护剩余时长位右上；通知左上；交互提示与小圆环留准星附近。用户要求集中的是身体与声音状态，不把瞄准交互圆环搬到远离目标的位置。左下区、中央快捷栏留24px净间隔；720p时状态宽240、文字最少16px，10格快捷栏可缩到42px/格，必要时窄屏改两行且不占左下状态区。

CanvasScaler以1080p参考、适配宽高，不用1600×900硬编码坐标。支持720p/1080p/1440p、16:9/16:10/21:9和80–150%UI缩放，中英文长文本不越界。满体力可淡出但布局锚点不变；体力/屏息耗空有文字/图形反馈，不只红绿。主菜单与详细页不显示现场状态。

声音从统一NoiseEvent发出，Audio、AI、HUD读取同一来源与有效强度；区分脚步/落地/工具/枪声/犬吠。蹲行不发Step事件，方向提示不泄露未听见的全图动物；墙体和距离衰减后才显示类别，持续0.8秒工程初值。无背景音乐。测试必须实际听到走/跑/蹲差异，并观察AI与提示一致，不能只把音量静音而AI仍听见。
